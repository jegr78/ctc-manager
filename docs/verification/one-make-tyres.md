# One-Make tyre verification

Issue #344 follows merged PR #346. Each race uses one Racing or Sports family. Both offer Hard, Medium and Soft. Racing also permits Intermediate and Wet as available compounds, never mandatory. Mandatory compounds may be empty and otherwise must be dry members of the available set. Sports requires the explicit CTC 2027 profile and a saved explicit One-Make entry. A filtered category with one member remains a category.
