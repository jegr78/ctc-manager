Backup

Download a complete archive or review a backup before restoring it.

Export Backup

Exports the full league database (all 27 entities) plus every uploaded file into a single ZIP archive. The download starts immediately and may take a few seconds for large leagues.

Import Backup

Restores the league database from a previously exported ZIP archive. Choose a file to review its contents, then proceed to confirmation. Restoring a backup replaces the current operational data and uploaded files. The upload is limited to 100 MB.
